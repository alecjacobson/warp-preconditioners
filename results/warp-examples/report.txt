* The recomputed float64 residual does not meet the example’s original
absolute stopping target. These times must not be presented as successful
time-to-accuracy comparisons. Magnetostatics also reaches its 250-iteration
limit under all tested preconditioners. Other marked examples report
recursive convergence despite the larger true residual.

A true-relative residual above the requested relative tolerance can still
satisfy the solver’s absolute tolerance floor; the validity check uses the
actual returned absolute target, not just relative residual.

The confirmed total-time wins that meet the original true-residual target
are mixed elasticity (10.16 to 6.54 ms, 1.55x) and the Stokes velocity-block
substitution (34.58 to 24.96 ms, 1.39x). Apparent wins in starred rows do not
establish a successful time-to-accuracy improvement.

Special cases and limitations
-----------------------------
- DG convection-diffusion is nonsymmetric (relative asymmetry about 0.774);
  direct FSAI construction violates its SPD contract and was not attempted.
- Darcy has 10099 negative interior diagonal entries and 102 positive
  boundary entries. FSAI rejects this unmodified system.
- Stokes transfer has 120 inactive zero diagonal entries; FSAI rejects them.
- Single-environment APIC has 461362 inactive zero rows in this snapshot;
  FSAI rejects them. Removing inactive rows would be an additional change.
- Saddle-point rows replace only the SPD velocity block of the existing
  block-diagonal preconditioner with FSAI. The original pressure Schur
  diagonal and full-system solver remain unchanged. Full saddle matrices
  are indefinite and cannot be passed directly to FSAI.
- Multi-environment APIC retains its original matrix-free, batched operator.
  FSAI requires assembling its pressure matrix; that assembly is charged to
  FSAI setup. Original diagonal construction is timed using its original kernel.
- Outer frame graph capture is disabled for snapshot extraction in APIC and
  Taylor-Green; solve replay uses CUDA graphs. Timings exclude whole-frame
  graphs. Dynamic FSAI setup cannot be inserted into the APIC frame graph.
- Fixed-matrix reuse can amortize setup. The CSV and raw JSON separate setup
  from solve time; no refit or factor-reuse speedup is claimed here.
- Default mesh choices only; this does not cover every CLI mesh/degree/frame
  combination or later nonlinear/optimization systems.

Excluded search matches
-----------------------
- example_diffusion_mgpu explicitly disables diagonal preconditioning.
- distributed/example_jacobi_{mpi,nccl,nvshmem} implement Jacobi relaxation.
- optim/example_fluid_checkpoint{,_custom_backward} use Jacobi pressure
  iterations, not Jacobi-preconditioned Krylov solves.

Files and reproduction
----------------------
inventory.json: source revision, settings, call sites, snapshot hashes, scope.
comparison.csv: all methods, setup/solve totals, iteration counts, residuals.
Per-example JSON: five raw samples for each method and rejection reasons.
Snapshots are generated into ignored data/warp-examples; no mesh download is needed.
Using the Warp checkout’s Python from this repository:
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /path/to/warp/.venv/bin/python \
  benchmarks/warp_example_fsai.py capture all
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /path/to/warp/.venv/bin/python \
  benchmarks/warp_example_fsai.py measure all --repeats 5
The measure-all command waits for idle GPU before each example; if another
GPU process appears during a trial, rerun the affected example.
